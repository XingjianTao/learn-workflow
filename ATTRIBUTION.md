# Sources and prior-art review

Reviewed on 2026-10-19 before implementation:

- [Matt Pocock, teach](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md): short interactive lessons, learning evidence and continuity. Its topic-based HTML curriculum is broader than this repository's fixed workflow rehearsal.
- [Matt Pocock, ask-matt](https://github.com/mattpocock/skills/blob/main/skills/engineering/ask-matt/SKILL.md): routing among engineering skills based on their actual definitions.
- [Matt Pocock, grilling and engineering skills](https://github.com/mattpocock/skills): decision interviews, specifications, vertical task slices, verification and review. The upstream repository uses MIT; we link to it and summarize relevant role contracts rather than copying its skill files.
- [AI Practice Lab](https://github.com/AzJester/AI-TRAINING): adjacent interactive training application. Its published rights statement did not support code/content reuse; none was copied.

The inspected sources did not offer a direct replacement for this exact combination of fixed, user-authored workflows, fictional artifact handoffs and one-exercise-at-a-time teaching. This is a bounded review, not a claim that no similar project exists.

The implementation, template and fictional cases here are original. Upstream skill installation, if desired for real work, is separate from installing these teaching skills. The package has no affiliation with or endorsement from the referenced authors.
